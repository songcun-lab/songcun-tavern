我的 AI 工具箱

这些是我每天真实在用的工具。没有赞助，没有推广，只有一个重度用户的诚实评价。 工具会换，但「把 AI 变成稳定工作流」这件事不会变。

对话与研究

ChatGPT
最早的入口，日常对话、思路梳理的主力。
Claude
长文写作和深度分析首选，文字质感最好。
Gemini
多模态和长上下文场景的补充。
Kimi
中文资料检索和长文档阅读。

AI 编程

Claude Code
我的主力编程 Agent，从它开始学会了氛围编程。
Codex
与 Claude Code 互为备份，各有擅长。
Cursor
需要在 IDE 里精细改代码时用。
VS Code + WSL
基础开发环境，Windows 下跑 Linux 工具链。

Agent 与自动化

Manus
复杂任务的通用 Agent：研究报告、网站、材料一站式完成。
Cowork
多 Agent 协作的探索。
Skills / MCP
把能力封装成可复用单元，是我最近研究的重点。

知识管理

Obsidian
第二大脑。按「资料原文—加工输出—沉淀知识」组织。
GitHub
所有学习成果的公开沉淀地，Songcun Lab 的家。
YouMind
素材收集和内容创作的中转站。

内容与设计

Lovart
视觉设计的 AI 助手，海报、配图、品牌物料。
小红书 / 朋友圈
每天一篇学习感悟的输出阵地，坚持一年多。
