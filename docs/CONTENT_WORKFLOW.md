# 宋村清酒小酒馆 · 长期写作 SOP

> 本文档是小酒馆的内容生产标准流程。目标：让写作从"灵感驱动"变成"系统驱动"，
> 十年尺度持续积累，不依赖任何单一工具或平台。
> 最后更新：2026-07-27

---

## 一、核心原则

1. **GitHub main 分支是唯一权威版本。** 所有内容以 `songcun-lab/songcun-tavern` 仓库 main 分支为准，不依赖本地副本或任何草稿平台。
2. **敏感内容一律先存 draft。** 涉及隐私、处分、家庭、医疗、债务、商业秘密的文章，frontmatter 设 `draft: true`，经本人审阅后才改为发布。
3. **有证据才写事实。** 涉及个人经历时间线的内容，以 GitHub commit、文件、照片等可验证证据为准；记不清的写"大约"或"待确认"，不虚构。
4. **短文不憋长文。** 一个观点能 800 字说清就不要写 3000 字。长文（2500+ 字）留给旗舰选题。
5. **一次写作，多端分发。** 博客是母版，小红书/朋友圈/X 是切片。先写博客，再裁切。

## 三、单篇文章生产流程（六步）

### 第 1 步：选题（5 分钟）
从内容地图选一个题，确认敏感分级：
- **A 级（可直接发布）**：纯知识、工具、行业观察
- **B 级（需自审后发布）**：涉及个人经历但已抽象处理
- **C 级（默认永久 draft）**：涉及处分细节、家庭、健康、债务

### 第 2 步：搭骨架（10 分钟）
按"背景—问题—判断—方案—下一步"或"故事—转折—反思—结论"搭出小标题。
写下这篇文章的**一句话核心观点**，放进 frontmatter 的 `description`。

### 第 3 步：写正文（1-3 小时，可用 AI 辅助）
可以口述给 AI 整理初稿，但**必须经过本人重写关键段落**——判断、故事、数字必须是自己的。
AI 只做：结构调整、错别字、补过渡句。AI 不做：编造经历、加空洞金句。

### 第 4 步：自检清单（10 分钟）
- [ ] 标题有具体信息量（数字/冲突/反直觉），不是营销号味
- [ ] 开头三句话内进入正题
- [ ] 中文语境用「」引号，不用英文直引号 ""
- [ ] 所有事实、时间、数字准确；记不清的标"大约"
- [ ] 敏感内容检查：无真实人名（除公开人物）、无单位可识别细节、无处分/健康/债务细节
- [ ] frontmatter 完整（见下方模板）
- [ ] 结尾有落点（一个判断/一个行动/一杯酒的余味），不强行升华

### 第 5 步：提交发布（5 分钟）
```bash
cd songcun-tavern
git pull --rebase origin main   # 必须先拉取
git add src/content/posts/新文章.md
git commit -m "post: 文章标题"
git push origin main
# 等 1-2 分钟，GitHub Actions 自动构建部署
```
或直接在 GitHub 网页端 `src/content/posts/` 目录点 Add file 编辑提交。

发布后检查：打开 `https://songcun-lab.github.io/songcun-tavern/blog/` 确认文章出现、排版正常。

### 第 6 步：分发切片（15 分钟，可选）
- **小红书**：取文中最有共鸣的一个故事/清单，300-800 字 + 3-5 个话题标签
- **朋友圈**：一段判断 + 文章链接，不超过 150 字
- **X/微博**：一句核心观点 + 链接
- 分享卡图片：每篇文章自动有 OG 分享卡（`public/images/og/文章slug.png`），可直接当配图

## 四、Frontmatter 模板

新建文章 = 复制此模板到 `src/content/posts/英文-slug.md`：

```yaml
---
title: "文章标题"
description: "一句话核心观点，也是搜索和分享时显示的摘要。"
date: 2026-08-01
category: ai          # ai / second-half / career / industry / startup / life
tags: ["标签1", "标签2", "标签3"]
featured: false       # 是否进首页"掌柜推荐"（全站保持 3 篇左右）
draft: false          # B/C 级内容先设 true
---
```

命名规范：文件名用英文小写连字符（如 `why-learning-ai-at-48.md`），这就是文章 URL。

## 五、节奏与仪式

| 周期 | 动作 |
|---|---|
| 每周 | 写 1 篇（A 级优先，B 级隔周），周末晚上发布 |
| 每月 | 更新 Now 页面（`src/pages/now.astro` 里的日期和"炉上三壶酒"）；从 draft 存货里审 1 篇转发布 |
| 每季度 | 对照 Now 页"接下来一个季度"逐条对账；内容地图补充新选题；检查失效外链 |
| 每年 | 写年度总结（人间杂谈）；重新生成 AI 数字年轮（跑一次 GitHub 考古）；备份仓库 |

**最低保障线**：再忙每月至少 1 篇。断更两周不自责，回来接着写即可——酒馆不打烊，只是掌柜出门了。

## 七、故障排查速查

| 问题 | 处理 |
|---|---|
| push 被拒 | 先 `git pull --rebase origin main` 再 push |
| Actions 失败 | 仓库 Actions 页看红叉日志；多半是 frontmatter 格式错（引号/日期） |
| 文章没显示 | 检查 `draft: true` 是否忘了改；date 是否是未来日期 |
| 本地预览 | `pnpm install && pnpm dev`，访问 localhost:4321/songcun-tavern/ |
| 分享卡缺失 | 新文章需重新生成 OG 卡（可让 AI 助手跑 generate_og_cards.py 脚本） |
