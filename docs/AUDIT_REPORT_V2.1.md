## 一、结论先行

**总体判断：网站内容基础是真实的，但存在三类系统性问题，本次已全部处理。**

第一类是**可验证但被写错的事实**。最典型的是"19 个 checkpoint 到 V10"——禾净官网仓库实际只有 12 个 commit，"19"这个数字 GitHub 无法支持（可能来自 Manus 平台内部 checkpoint 计数，但那不是 GitHub 证据）。此类已按可验证口径统一修正。

第二类是**时区误读造成的叙事失真**。GitHub 时间戳是 UTC。"2 月 6 日凌晨两小时建成 codex-notes"，按北京时间实际是**中午 12:40 到下午 14:50**；"1 月 20 日晚 19:00 写下第一篇实测"，按北京时间是 1 月 21 日凌晨 3 点。原文用"凌晨""当晚"渲染了并不存在的深夜奋斗叙事。此类已全部改为标注 UTC 或删除钟点修饰。

第三类是**无材料依据的绝对化与量化表述**。"一天没断过"（出现 5 处以上）、"产出效率至少三倍"、"想放弃三次"、"深夜十一点改到第 14 版"——这些细节听起来合理，但没有任何材料支撑，属于典型的 AI 幻觉补全或成功学式表达。此类已全部软化或删除。

**5 篇 draft 文章全部保持 draft:true，未发布**。每篇的源文件头部已加入 `<!-- V2.1 审计提醒 -->` HTML 注释，列出需要本人逐项确认的事实点，是否发布由宋博士本人决定。

**遗留的最高优先待确认项有 6 个**（见第六节），主要涉及本人回忆类经历和公开意愿决策，AI 无权代为定夺。
