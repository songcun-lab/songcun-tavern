先交代背景：我不是程序员，也不是数码博主。我是能源行业出身的管理者，2025 年前后开始系统学 AI，一年多下来，GitHub 组织里攒了 41 个仓库，试过的工具两只手数不过来。

这篇文章不推荐工具。我想回答一个更实际的问题：**折腾了这么久，最后真正留下来的是什么？**

## 先说被淘汰的

被我放弃的工具，死因高度一致，无非三种。

第一种死因：**只能演示，不能干活**。有些工具第一眼惊艳，录个屏发朋友圈效果极好，但真拿自己的活儿喂给它，两三次之后就露馅。演示价值和生产价值是两回事——这个判断我在智能矿山行业见过太多次，没想到在自己桌面上又见了一遍。

第二种死因：**要求我迁就它**。工具要求我改变文件格式、换个笔记体系、把资料搬进它的私有云。年轻时候我可能愿意折腾，现在不了。我的判断是：**好工具嵌入你的工作流，坏工具要求你重建工作流。**

第三种死因：**没有沉淀**。用完即走，什么都不留下。聊天记录躺在别人的服务器里，搜不到、导不出、复用不了。这类工具再聪明，也只是消费，不是积累。

## 留下来的，和为什么

潮水退去，我桌面上常驻的东西其实不多。

**ChatGPT 留下了**，角色是「第一个对话者」。想法还是一团浆糊的时候找它，问题还问不清楚的时候找它。它是我思考的草稿纸。

**Claude 和 Claude Code 留下了**，角色是「干活的」。文字加工、长文档处理、写代码改代码，都是它。今年 1 月 20 日晚上，我在 GitHub 上写的第一篇工具实测笔记就是 Claude Code 的 First Impression，当晚还做了它和 Gemini CLI 的对照实验。一年多过去，它是被验证次数最多的那个。

**Obsidian 留下了**，角色是「第二大脑」。所有 AI 产出的东西，最后值得留的都会回到 Obsidian 的库里。4 月份我把整个库连进了 GitHub，从此笔记有了版本历史。

**GitHub 留下了**，而且地位远超预期。它从「程序员的网站」变成了我的**总仓库**：知识库在上面、提示词库在上面、公司官网在上面、连这间小酒馆也在上面。对非程序员来说，GitHub 真正的价值不是代码托管，是给你的数字资产一个可以传十年的地基。

**Manus 这类 Agent 留下了**，角色是「执行者」。研究报告、批量处理、建站部署，交代清楚就去干活。它和 Claude Code 的分工是我花了不少学费才想明白的：一个擅长按我的意图长时间自主作业，一个擅长在我的仓库里精确施工。

## 三条筛选标准

如果把一年多的取舍压缩成判断标准，是这三条。

**一，它产出的东西能不能变成资产。** 输出能不能存成 Markdown、进我的仓库、被将来的我搜到。能，就有资格留下；不能，再好玩也是消费。

**二，它是不是嵌入我已有的流。** 我的流很简单：想法（朋友圈/对话）→ 加工（Claude/Manus）→ 沉淀（Obsidian/GitHub）→ 输出（博客/方案）。新工具必须接进这条流的某一段，而不是另起炉灶。

**三，离开它我会不会难受。** 每季度我会问自己一遍：假如这个工具明天关闭，我的工作流断不断？断，说明它是基础设施，值得深耕；不断，说明它是甜点，随时可弃。

## 最后留下的其实不是工具

写到这里可以摊牌了。折腾一年多，最值钱的收获不是任何一款工具，而是三样看不见的东西。

**一套工作流**。工具会过时，流不会。ChatGPT 可以换成任何对话模型，Claude Code 可以换成任何编程 Agent，只要「想法→加工→沉淀→输出」这条流还在，换零件不伤筋骨。

**一堆提示词资产**。2 月 6 日凌晨，我花两个小时把散落的提示词整理成模板库（debug、refactor、通用模板），从那以后每个好用的提示词都会归档。它们是我和 AI 协作的「标准作业程序」。

**一种判断力**。现在再看到新工具发布，我大概十分钟就能判断它属于「演示型」还是「生产型」，属于「基础设施」还是「甜点」。这个判断力，是用几十次踩坑换来的，也是这篇文章真正想传给你的东西。

工具的尽头是工作流，工作流的尽头是判断力。

酒馆今晚的这壶酒，敬所有交过的学费。
